## Getting Started

The `portfolio_manager/your-nextjs-app` directory is your main working directory. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Technical Requirements
- Docker
- Git

### Clone the Repository

Once you have installed [Git](https://git-scm.com/downloads), clone this repository:

```
git clone https://github.com/vasuquantdev/bbit-learning-tool.git
cd bbit-learning-tool/web_development
```

### Run with Docker

[Install Docker](https://docs.docker.com/get-docker/) for your operating system, then from the `web_development` directory run:

```
docker compose up
```

This starts WordPress, MariaDB, and the Next.js development servers. Dependencies are installed automatically on first run.

3. Your web application should be running. Open the `portfolio_manager/your-nextjs-app` directory in your editor to begin the labs.

4. Open [http://localhost:3000](http://localhost:3000) to work on your application, and [http://localhost:3001](http://localhost:3001) to view the completed reference version.
